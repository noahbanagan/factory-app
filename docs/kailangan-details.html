Mga Details na Kukunin sa Shop

Checklist para sa operators at programmer. Lahat ng ito ay kailangan para ma-finish ang CAM setup para sa CNC1, CNC2 at BA24. One-time lang, pero kailangan tama. I-print, i-fill up, tapos i-send kay Sir Noah.

Paano i-send: picture o file sa group chat o email kay Sir Noah, with label kung aling machine (CNC1 / CNC2 / BA24). Ang tool measurements ay direkta sa Google Sheet Dynamic CNC Tool Inventory - QP1620, tab CNC1 o CNC2.

A. Sa CNC1 at CNC2 (Fanuc 0i-MD)

1

Spindle at machine plate operator

Picture ng name plate ng machine (sa gilid o likod) at ng spindle plate. Kailangan makita: model, serial number, year, max RPM.

Isulat: CNC1 serial · CNC2 serial

Send: 2 pictures per machine.
2

Ethernet screen ng control operator

Sa Fanuc: pindutin SYSTEM, tapos hanapin sa soft keys ang ETHPRM, Ethernet, o EMBED (pindutin ang ▶ arrow soft key para makita ang iba pang keys). Picture ng screen na lumabas. Kailangan makita kung may IP address, at kung may nakasulat na FTP, Data Server o FOCAS.

Kung walang Ethernet na lalabas, picture pa rin ng SYSTEM screen at sabihin "wala".

IP ng CNC1 · IP ng CNC2

Send: picture ng screen per machine, at ang IP kung meron.
3

Isang proven program na tumakbo na sa machine programmer

Kumuha ng isang .NC file na galing sa X5 na na-run na nang maayos sa QP1620, kasama ang DXF ng parehong parte. Mas maganda kung job na may pocket, drill at tap. Halimbawa: Mahle lower mold, o kahit anong Semitec plate.

Program number · Part · Material

Send: ang .NC file + ang .DXF file (hindi screenshot).
4

Parameter 3741 (max spindle RPM sa control) operator

Sa Fanuc: SYSTEM → PARAM → i-type 3741 → NO.SRH. Picture ng value. Ito ang confirm kung 10000 talaga ang max ng machine.

CNC1 value · CNC2 value

Send: picture per machine.

B. Tools sa bawat machine

5

I-measure lahat ng tools na nasa magazine operator

Para sa bawat tool na nakalagay sa tool changer ng CNC1, tapos ng CNC2. Ilagay sa Google Sheet, tab ng machine na iyon, isang row per tool. Caliper ang gamit, mm lahat.

Column sa sheetPaano kunin
PocketNumber ng pocket sa magazine kung saan nakalagay
TTool number na tinatawag sa program (usually same sa pocket)
Type at Diaflat / ball / bull / face / chamfer / drill / spot / tap / ream, at diameter
FlutesBilangin ang cutting edges
FluteLenCaliper: haba ng may cutting edge (flutes)
StickoutCaliper: tip ng tool hanggang flat na nose ng holder, habang nakakabit sa holder
HolderDiaCaliper: pinakamalapad na part ng nose ng holder
ShankDiaDiameter ng shank kung iba sa cutter (hal. 6 mm cutter na 8 mm shank)
Loadedyes kung nasa machine ngayon
PitchTaps lang: pitch ng thread (M8 = 1.25, M6 = 1.0, M3 = 0.5)
AngleDrills at spot drills lang: 118 o 135 para sa drill; 90 para sa spot/chamfer
Send: nothing, direkta sa sheet. Tapos sabihin "tapos na ang CNC1" / "tapos na ang CNC2".
6

Tools sa shelf na hindi nakakabit operator

Same sheet, isang row per tool, pero Loaded = no at walang Pocket. Lalo na ang maliliit: Ø2, Ø2.5, Ø3, Ø4 end mills at drills. Dito malalaman ng CAM kung ano ang puwedeng gamitin sa slots ng Semitec.

Pinakamaliit na end mill na meron · pinakamaliit na drill

Send: direkta sa sheet.
7

Holders at collets operator

Ilang BT40 holders meron (ER32, ER16, side lock, face mill arbor, drill chuck) at ilang piraso bawat isa.

Send: listahan o picture ng holder rack.

C. Paano naka-clamp ang parte

8

Vise at clamps operator

Picture ng vise sa table na may naka-clamp na plate, from the side. Caliper o steel rule:

  • Taas ng jaw mula sa table mm
  • Kapal ng jaw (front to back) mm
  • Max opening ng vise mm
  • Parallels na gamit: kapal mm
  • Kung toe clamps: taas ng clamp pag nakakabit mm

Sabihin din: usually gaano kalalim nakapasok ang plate sa jaw (hal. 5 mm lang) at kung may soft jaws.

Send: 2 pictures per machine + ang mga numero.

Control model · wire diameter na gamit · ilang passes usually

E. Tungkol sa mga tao at daloy

10

Mga operator supervisor

  • Ilang operators, at sino ang sa CNC1, CNC2, BA24
  • Kaya ba nilang mag-set ng G54 at tool length (H) mag-isa? (yes / no / partly)
  • Marunong bang magbasa ng drawing na may tolerance?
  • Gmail address ng bawat operator (para sa login at Google Sheet)
  • English o Taglish ang gusto sa screen
11

Daloy ng trabaho supervisor

  • Saan nagsisimula ang job para sa operator: printed drawing, email, o Drive
  • Sino ang nag-a-approve ng program at setup sheet bago mag-run
  • Sino ang nagdedesisyon kung mill o wire cut ang parte
  • Paano nilo-load ang program ngayon: USB, RS-232, o network
12

Hosting at accounts Sir Noah

  • I-on ang GitHub Pages (Settings → Pages → main, root) para may permanent link
  • I-publish ang CNC1 at CNC2 tabs ng tool sheet bilang CSV, i-paste ang 2 links sa CAM Settings
  • Google Cloud: API key (Drive links) at OAuth client (job queue, sign-in)
  • Anthropic API key, o hintayin ang installer login
